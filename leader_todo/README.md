# リーダー TODO

主任 TODO（最新TODO EX）の機能をそのまま引き継いだ、リーダー向けの新しいデスクトップアプリです。
対象者は **岸・高野・髙岩** の3名です。データは主任 TODO とは別のフォルダーに保存するので、同じPCで両方使えます。

## 主な機能

- 主任 TODO と同じ機能: ホーム、日次チェック（早番・遅番）、自由 TODO（繰り返し・優先度・分類）、カレンダー、リーダー記録（週次・月次PDFレポート）、HP 画像チェック、関連リンク、Excel 取り込み、自動保存とバックアップ、キーボード操作
- **テーマ**: 「標準」と「黄金騎士」の2種類（画面右上か設定画面で切り替え）
- **成長の可視化（ドル箱）**: リーダー記録1件＝ドル箱1箱。記録するほどドル箱が積み上がります。
  - 「全員」タブ: 3人の島を並べて表示し、出玉ランキングと合計を表示
  - 個人タブ（岸・高野・髙岩）: その人のドル箱・出玉・連チャン（連続記録日数）だけを表示
  - 1箱の出玉は記録の文字数で決まります（最低250発、満タン2,000発）
- **共有（JSONのやり取り）**
  1. 設定で「このPCを使う人」を選ぶ
  2. 「共有用に書き出す」で `リーダーTODO_共有_名前_日時.json` を作り、Teams や共有フォルダーで渡す
  3. 受け取った人は「共有データを取り込む」を押す。取り込みは**足し合わせ**なので、自分の記録・TODO は消えません
  - 同じ項目が両方で変更されていたときは、あとから変更した方を残します
  - 削除した TODO・予定・リンクは、他の人のデータから復活しません
  - 日次チェックの状態・テーマ・使用者の設定は取り込みで変わりません
  - 取り込む前の状態は `backups` に自動で保存されます

## 黄金騎士モードの演出

パチンコ機の演出の流れを業務に結びつけています。画像・音声・ロゴなどの素材は使わず、CSS・SVG・合成音で作ったオリジナル演出です。

| 業務の動き | 演出 |
| --- | --- |
| 未完了 TODO | 画面上部の**保留**（白＝通常、青＝3日以内、緑＝優先度高、赤＝今日まで、金＝期限切れ） |
| TODO を追加 | 保留が点灯（保留変化） |
| TODO を完了 | **予告カットイン**（青→緑→赤→金→虹。期限切れは金、今日までは赤） |
| 日次チェックが残り1件 | **リーチ** |
| 日次チェックを全部完了 | **GOLD RUSH 突入**（大当り演出） |
| 未完了 TODO がゼロ | **全TODO撃破 BONUS** |
| リーダー記録を追加 | 玉の**払い出し**とドル箱 +1。10箱ごとに**大当り**、3日以上の連続記録で**連チャン** |
| 日次更新 | 精算カットイン |
| 共有データを取り込む | 仲間の出玉が合流 |

- サイドバーのデジタル表示: 総出玉・自分の出玉・連チャン・RUSH ゲージ（今日の日次チェック達成率）
- 設定で演出の強さ（控えめ／標準／全開）と演出音のオン・オフを切り替えられます（音は初期状態でオフ）
- 「演出を試す」で一通りの演出を確認できます
- OS の「視差効果を減らす」設定が有効なときは、画面全体の演出を止めて通知だけにします

## exe の入手

GitHub Actions の「Build リーダーTODO (Windows exe)」が `leader_todo/` の変更ごとに Windows 上で exe をビルドします。
Actions の実行結果の **Artifacts → LeaderTODO-exe** から `LeaderTODO.exe` をダウンロードしてください。

手元でビルドする場合（Windows・Python 3.11）:

```bat
cd leader_todo
pip install -r requirements.txt pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name LeaderTODO --icon icon.ico --add-data "web;web" --add-data "icon.ico;." desktop.py
```

`dist\LeaderTODO.exe` ができます。実行には Microsoft Edge WebView2 ランタイム（Windows 10/11 には標準で入っています）が必要です。

## 保存場所

`%APPDATA%\リーダーTODO\state.json`（毎日の自動バックアップは `backups` フォルダー）

## 構成

- `desktop.py` … ウィンドウとファイル保存を担当する本体（pywebview）
- `web/` … 画面（HTML・CSS・JavaScript）。起動時に1ページにまとめて読み込みます
  - `share.js` … 共有データの取り込み（マージ）
  - `garo.js` / `garo.css` … 黄金騎士モードの演出
  - `growth.js` / `dollbox.css` … 成長の可視化（ドル箱）
- `tests/` … 画面を開かずに確認できるテスト（`python -m unittest discover -s tests`）
